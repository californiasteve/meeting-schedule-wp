Where meetings come from

The aggregator searches every public BMLT server at once. Pick a single root server to work from its own data, or paste any server address.

Day names and the printed headings use the first language, and format names come from the server's own translations. Changing it reloads the meetings. Pick a second language to print each day in both, such as “Monday / Lunes”.

Paper and columns

For a trifold or quad fold, print double-sided and flip on the short edge. The front panel goes in the last column of page 1, which becomes the cover once folded.

Front page or panel

Quick pick
Logo

Select text and use the toolbar to style it, or type **bold**, *italic*, __underline__. Start lines with - for a list, and leave a blank line between paragraphs. Shortcodes such as {date} and {count} work here and in the title and subtitle; see the Content tab for the full list.

Your own content

Add welcome text, service committee info, a phone list or anything else your printed list carries. Type three or more underscores, like Name ___, for a solid write-in line that runs to the edge of the column. + Line in the toolbar adds another one; in a list like Name ___ / Phone ___ it adds a whole new entry.

Starter blocks

These are the four blocks every new schedule starts with. Add one back any time, even after removing it.

Shortcodes

Type a shortcode in curly brackets anywhere: the title, subtitle, front text, block headings and text, and the meeting and time templates. Built in: {date} this month and year, {month}, {year}, {today} the full date, {count} all meetings, {in_person}, {virtual}, {hybrid}, {area} or {service_body} the service bodies you picked, and {cities} and {counties} every city and county the listed meetings are in, A to Z. {helpline} and {url} are the helpline and website your BMLT server lists for the service body you picked (the first one that has them). A line of your own with the same name replaces them.

One per line, as name = text. Then {name} prints that text wherever you use it, so a phone number or web address only has to be changed in one place.

How meetings are grouped

Meeting details

Put each item on its own line to stack them. The first line is bold; lines below it are smaller. Use the field buttons below to add {end_time}, {formats}, {venue} and so on.

Each line prints as a line. Text in [square brackets] is left out when a field inside it is empty, so [Room: {info}] only prints when there is room info. Click a field to insert it. The toolbar styles the selected text.
